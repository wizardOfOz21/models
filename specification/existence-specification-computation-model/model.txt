# Модель существование-задание-вычисление

## Краткое описание

Модель разделяет три уровня знания о функции: что она существует, как её можно задать и как реально вычислить её значение. Функция может быть известна на любом уровне, не доходя до следующего

## Полное описание

### Применимость

Источник модели: вопрос о том, как соотносятся формула, определяющая величину, и другие формулы, которыми её можно вычислить. Применяется в первую очередь к математике, на конкретных случаях, например масса графов с заданными валентностями (сумма единиц на порядок группы автоморфизмов)

### Описание

Слово «утверждение» используется в общем, интуитивном смысле, без привязки к конкретной логике. Модель понятийная, не математическая структура

Предмет модели называем функцией. Он не обязательно числовой: это может быть отображение между структурами, построение на множествах и т. д.

Есть три уровня знания о функции

**Уровень 1. Утверждение существования** Известны свойства функции и известно, что функция с такими свойствами существует. Способа её найти или записать нет

**Уровень 2. Способы задания** Есть конкретные способы задать функцию: формула из определения, формулы из теорем, любые другие выражения. Их можно использовать в доказательствах и теоремах. Они не обязаны быть вычислимыми: наличие формулы не означает, что значение можно получить для любых входных данных за разумное время

**Уровень 3. Вычисление** Значение реально можно вычислить на конкретных входных данных за разумное время

**Отношения между уровнями**
- Каждый уровень вниз влечёт вышестоящий: если есть способ задания, функция существует
- Обратное неверно: можно остановиться на любом уровне, не дойдя до следующего
- Функция, определённая формулой, уже находится на уровне 2. Другие формулы той же функции, после доказательства эквивалентности, равноправные способы задания

## Ключевые идеи

- Формула из определения и другие способы вычисления той же функции связаны отношением, а не конкурируют: после доказательства эквивалентности они равноправны
- Функция может быть известна на любом уровне, не доходя до следующего: можно знать только, что она существует, или иметь формулу и не уметь вычислить
